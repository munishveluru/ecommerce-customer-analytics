# Power BI DAX Measures Definition

This document details the DAX (Data Analysis Expressions) formulas designed for the **E-Commerce Customer Analytics and Segmentation Dashboard** data model.

---

## 📌 Core KPIs

### 1. Total Spend (Revenue)
*Calculates the total monetary value generated from all e-commerce transactions.*
```dax
Total Spend = SUM(fact_transactions[order_value])
```

### 2. Total Orders
*Counts the total number of transactions processed.*
```dax
Total Orders = COUNT(fact_transactions[transaction_id])
```

### 3. Active Customers
*Counts the number of unique customers who have made at least one purchase.*
```dax
Active Customers = DISTINCTCOUNT(fact_transactions[customer_id])
```

### 4. Average Order Value (AOV)
*The average amount spent by a customer per order.*
```dax
Average Order Value = DIVIDE([Total Spend], [Total Orders], 0)
```

---

## 📊 RFM Customer Profiles

### 5. Average Recency (Days)
*The average number of days since customers last purchased.*
```dax
Average Recency (Days) = AVERAGE(dim_customers_processed[recency_days])
```

### 6. Average Frequency (Orders)
*The average number of orders placed per customer.*
```dax
Average Frequency = AVERAGE(dim_customers_processed[frequency_orders])
```

### 7. Average Customer Spend
*The average lifetime spend of customers.*
```dax
Average Customer Spend = AVERAGE(dim_customers_processed[monetary_spend])
```

---

## 📈 Share & Contribution Percentages

### 8. Revenue Contribution %
*The percentage of total sales generated by a specific customer segment or group.*
```dax
Revenue Share % = 
DIVIDE(
    SUM(dim_customers_processed[monetary_spend]), 
    CALCULATE(SUM(dim_customers_processed[monetary_spend]), ALL(dim_customers_processed)), 
    0
)
```

### 9. Segment Size (Customer Count %)
*The proportion of the customer base belonging to a specific segment.*
```dax
Segment Customer Share % = 
DIVIDE(
    COUNT(dim_customers_processed[customer_id]), 
    CALCULATE(COUNT(dim_customers_processed[customer_id]), ALL(dim_customers_processed)), 
    0
)
```

### 10. Month-over-Month (MoM) Spend Growth
*Tracks monthly trends in transaction volume.*
```dax
MoM Spend Growth = 
VAR CurrentMonthSpend = [Total Spend]
VAR PreviousMonthSpend = 
    CALCULATE(
        [Total Spend], 
        DATEADD('Calendar'[Date], -1, MONTH)
    )
RETURN
    DIVIDE(CurrentMonthSpend - PreviousMonthSpend, PreviousMonthSpend, 0)
```
